# 从主题到图文

用户的参考优先于预设。主题影响整套视觉和内容节奏，而不只是换横幅。保持产品既有名称、品牌和事实；先选少量高价值素材。

## 北欧目录 / 宜家风格

- 明亮白底，米白、浅木、亚麻、少量植物绿；借用宜家画廊的日常、实用、亲切感。
- 用自然光的生活场景表达产品气质，构图像目录摄影。保留现有应用图标，不复制宜家标志或暗示品牌关联。
- 首屏放主题封面和简明定位；功能展示是几组真实图片加短说明；快速开始清晰可复制，技术细节可折叠。
- 图片中的标题要少、准确、在手机上能看清。必要时仅放品牌名，长句留在 README 原生文字中。
- 真截图不改成不存在的功能；概念图与演示项目截图用 caption 标明。截取范围避免真实密钥、个人数据和不相关的项目目录。

## 自定义主题

记录参考、主题名称、背景与强调色、画面材料、图片构图、图像类型、文字与图片的分工。可以迁移到杂志、复古像素或深色技术等风格，不把固定排版套给所有项目。

## 更新

事实和设计分开管理。名字、功能、版本、入口来自证据；主题负责呈现。用户锁定的图文保留。替换过时内容前说明依据；未变化的视觉资源不重新生成。
